## 評審 17 項總檢（最終）
| 項目 | 結論 |
|---|---|
| 1 是否符合作業要求 | 六項要求逐頁對應，見 `99-final-checklist.md` |
| 2 概念清楚 | 一句話：浴室——最私密、最難被發現 → 守護，但不窺視 |
| 3 視覺層級 | 每頁一個主張句標題；主視覺 → 說明 → 出處 |
| 4 構圖 | 12 欄網格、固定邊界；情境頁左文右圖、流程頁左圖右梯 |
| 5 Typography | 襯線主標／黑體內文／楷體＝人的聲音／等寬＝時間與數據，語意固定 |
| 6 色彩 | 墨／紙兩種底色；琥珀＝關心與光、朱紅＝危險、灰藍＝感測範圍，無裝飾性漸層 |
| 7 Spacing | 檢查工具確認無安全區溢出、無文字重疊 |
| 8 Motion continuity | 跨頁延續的 HUD（章節、時間・地點、進度線）；「浴室」match cut；夜↔日以時間軸線擦換 |
| 9 Easing | 全片四種曲線：expo.out / power2.inOut / power2.in / back.out |
| 10 Timing | 群組內 stagger 0.06–0.12 s；自動播放依講稿長度 |
| 11 Transitions | 只在「夜→日」切換時使用擦換；同底色頁面安靜切換 |
| 12 易懂 | 流程頁先顯示完整邏輯，再用情境模擬「跑一次」 |
| 13 模板感 | 無卡片陰影 UI；平面圖、時鐘、流程梯皆為內容本身 |
| 14 AI 感 | 無漸層光暈裝飾、無通用 icon 牆；每個數字有出處 |
| 15 技術穩定 | 離線可開、無 console error、任意時間點可重現 |
| 16 完成度 | 簡報、PDF、書面報告、影片、講稿皆完成 |
| 17 老師可能扣分處 | 「預計結果」皆為設計目標而非實測 → 已明確標註並附驗證方法；情境為示意 → 參考資料頁說明 |
