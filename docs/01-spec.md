# 01 · 作業規格（Specification）

> 來源：課程「健康物聯網趨勢與創新」(臺北醫學大學) 兩份講義與作業要求截圖
> - `1150910` 講義：物聯網簡介（1-1 定義、1-2 目的與重要性、1-3 物體智慧化、1-4 各國現況、1-5 結語）＋健康物聯網架構圖
> - `1150917` 講義：物聯網的架構（2-1 感知層、2-2 網路層、2-3 雲端計算層、2-4 資料分析層、2-5 應用層、2-6 結語）＋**「課堂：設計與應用」**（最後一頁，即作業要求截圖）
>
> 本文件是本專案的最高優先依據。所有製作決策都回到這裡檢查。

---

## 1. 作業目標

以課堂所學的**健康物聯網五層架構**（感知層 → 網路層 → 雲端計算層 → 資料分析層 → 應用層），
從「關心身邊的人」出發，**設計一個具人文關懷的健康物聯網應用**，並以期中報告形式提出。

## 2. 必做內容（截圖逐條，原文照錄）

| # | 截圖原文 | 本專案的具體交付 |
|---|---|---|
| R1 | 對家人的關心…（時間、地點） | 情境 A：獨居的祖母。明確寫出**時間**（夜間 22:00–06:00，關鍵時刻 02:13）與**地點**（臥室 → 走廊 → 浴室，附平面圖） |
| R2 | 對週遭同學、朋友的關心…（時間、地點） | 情境 B：在外租屋的同學。明確寫出**時間**（冬季晚間 20:00–24:00 洗澡時段）與**地點**（租屋套房浴室＋陽台熱水器，附平面圖） |
| R3 | 設計人文關懷的議題 | 議題：「浴室——最私密、也最危險的空間」。在**安全與尊嚴/隱私**之間取得平衡：守護，但不窺視（全系統不使用鏡頭） |
| R4 | 想想有甚麼感測器可以應用上 | 感測器清單＋選用理由＋擺放位置（毫米波雷達、PIR、門磁、床墊壓力、溫濕度、一氧化碳、按鈕/語音），並標示在平面圖上 |
| R5 | 設定監測流程 | 兩條監測流程（跌倒/久滯、CO），含觸發條件、門檻、時間窗、逐級通報（本人 → 家人/朋友 → 社區 → 119） |
| R6 | 預計結果及效益 | 以「設計目標」呈現的可量測預期結果（不捏造實測數據）＋對本人/家人/朋友/社會的效益，另列限制與下一步 |

## 4. 格式與技術要求

- 截圖未規定格式、頁數、時間。依課堂期中報告慣例做出以下決策：
  - **口頭簡報**：16:9 網頁簡報，約 **8–10 分鐘**，20 頁以內，附講稿。
  - **可繳交檔案**：簡報 PDF（每頁完成狀態）＋ A4 書面報告 PDF ＋ 自動播放影片 MP4（備用展示）。
  - 語言：繁體中文（專有名詞附英文）。
  - 離線可用：教室電腦可能無網路——字型、程式庫全部內嵌於 repository，直接開啟 `index.html` 即可。
- 參考資料需可追溯（機構、年份、網址），不捏造。

## 5. 評分標準（截圖未列出；依作業要求推定）

1. 六項要求是否逐條回應（特別是「時間、地點」是否具體）
2. 人文關懷議題是否有說服力、有真實問題依據
3. 感測器選擇是否合理、可實作
4. 監測流程是否完整、邏輯清楚（含誤報處理）
5. 預期結果與效益是否具體、可衡量
6. 是否運用課堂所學（五層架構、網路技術、雲端服務型態）
7. 簡報清楚度與表達

## 6. 時間／長度限制

- 未規定 → 自訂：簡報 8–10 分鐘；書面報告 A4 約 6–8 頁。

## 7. 需要研究的主題

- 臺灣高齡化與獨居長者現況（官方統計）
- 長者跌倒的盛行率、地點、後果；跌倒後長時間倒地（long lie）
- 穿戴式緊急按鈕實際使用率問題
- 夜尿與跌倒的關聯
- 臺灣一氧化碳中毒事件與熱水器安裝問題（消防署）
- 一氧化碳警報門檻標準
- 非影像感測（毫米波雷達）用於跌倒偵測的可行性
- 長照 2.0／緊急救援服務的現有資源（銜接對象）
