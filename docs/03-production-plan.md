# 03 · 製作企劃

## 1. 核心概念

**「你還好嗎？」——安在 AnZai：不用鏡頭的浴室安全守護系統**

- 作業要求「對家人的關心」與「對同學、朋友的關心」，並各自標明**時間、地點**。
  研究後發現兩個看似無關的情境，落在同一個地點：**浴室**。
  - 家人：獨居的阿嬤，**凌晨 02:13**，夜裡起身走「臥室 → 走廊 → 浴室」。
  - 朋友：外宿的同學，**冬夜 22:40**，關緊窗戶洗熱水澡，屋外式熱水器裝在加了窗戶的陽台。
- 人文關懷議題：浴室不是跌倒次數最多的地方（臥室 35.6%、浴室 17%），卻是**最私密、門會關上、最難被發現、也最不可能裝鏡頭**的地方。
  → 議題命名：**守護，但不窺視**（安全 vs. 尊嚴）。
- 系統的終點不是警報，而是讓「人」更早說出一句「你還好嗎？」——數據觸發人與人的關心，而非取代。

## 3. 視覺方向

**夜與微光。** 夜間情境用墨色背景，分析段落用紙色背景；唯一的暖色是「夜燈的琥珀光」。

| Token | 色碼 | 語意（只用在這個意義上） |
|---|---|---|
| ink | `#11161D` | 夜間場景背景 |
| paper | `#F2EDE4` | 分析／說明場景背景 |
| amber | `#E8A33D` | 系統的「關心」：夜燈、詢問、在場的人（光點） |
| vermilion | `#D2462F` | 危險：跌倒、CO 超標、L2/L3 警示 |
| slate | `#7F93A8` | 感測範圍、資料流 |

- 不使用漸層、不使用裝飾性光暈、不使用卡片陰影。唯一的「光」是夜燈本身（有意義）。
- 平面圖：建築製圖語彙（粗牆線、門弧線、細家具線），呈現「地點」。
- 時鐘：等寬數字，呈現「時間」。
- **時間 × 地點**＝本作品的視覺文法：每個情境頁都同時有一個時鐘與一張平面圖。

## 4. 資訊層級

1. 主張句標題（Noto Serif TC，56–88 px）——每頁只有一個主訊息。
2. 主視覺（平面圖、數字、流程梯）。
3. 說明文字（Noto Sans TC，24–30 px）。
4. 註腳與出處（IBM Plex Mono / Noto Sans TC，16 px，編號對應參考資料頁）。

## 5. Typography

## 6. 構圖

- 畫布 1920×1080，等比縮放置中。左右邊界 120 px、上 120 px、下 100 px，12 欄網格（欄距 32 px）。
- 頂部 HUD：左＝章節；右＝情境頁才出現的「時間・地點」。底部：章節進度線＋頁碼。
- 情境頁固定「左文右圖」；流程頁固定「左圖右流程梯」。

## 7. 動態設計邏輯

| 原則 | 實作 |
|---|---|
| Hierarchy | 進場順序永遠是：標題 → 主視覺 → 說明 → 出處；不讓所有元素同時移動 |
| Rhythm | 群組內 stagger 0.06–0.12 s；群組之間留 0.2–0.4 s 呼吸 |
| Anticipation | 光點出發前先微縮回彈；天平先往一邊傾再回正 |
| Follow-through | 進場使用 expo.out / power3.out（快進、長收尾）；數字跳動結尾減速 |
| Controlled easing | 全片只用 4 種曲線：`enter`=expo.out、`move`=power2.inOut、`exit`=power2.in、`settle`=back.out(1.4)（只用於小元素落定） |
| Continuity | 頁面切換用一條「時間軸線」橫掃；S1→S2 用 match cut（「浴室」二字留在原位成為下一頁的主角）；底部進度線與 HUD 時鐘跨頁延續 |
| Purpose | 動畫只用來表達：時間流逝（時鐘、路徑）、因果（流程節點依序點亮）、數量（計數、點陣） |

## 9. 技術實作

- **HTML + CSS + 原生 JavaScript + SVG + GSAP 3.15**（含 MotionPathPlugin；GSAP 自 2025 年起完全免費）。
  - 選擇理由：時間軸可**任意定位（seek）**→ 能在任何時間點精準截圖、逐格輸出影片、PDF 取每頁完成狀態。
  - 所有動畫只由 GSAP 驅動（不用 CSS animation），確保可 seek、可重現。
- 傳統 `<script>`（非 ES module）＋內嵌字型 → 以 `file://` 直接開啟可用，不需伺服器、不需網路。
- 簡報引擎：每頁一條 timeline，步驟以 `addPause` 分段；→ 前進一步、← 回到上一步（瞬間定位）。
- 輸出：
  - `tools/export-pdf.mjs`：Playwright 逐頁定位到完成狀態 → 向量 PDF（文字可搜尋）。
  - `tools/render-video.mjs`：建立「主時間軸」（含轉場與停留），逐格 seek → JPEG → ffmpeg H.264。
  - `tools/inspect.mjs`：每頁每步驟截圖、0/25/50/75/100% 截圖、console error、文字溢出偵測。
